# GT Studio — Portfólio

Portfólio de fotografia e audiovisual da GT Studio (Gabriel Mota).
Página única e autocontida (`index.html`): fotos, vídeos, estilos e scripts já estão embutidos.

## Como visualizar
Abra o `index.html` no navegador.

## Publicar no GitHub Pages
Settings → Pages → Branch: `main` / pasta `/ (root)` → Save.

## Onde editar
- Contatos: bloco `IC` / lista de botões no final do `<script>`.
- Texto do fundador: seção `id="gabriel"` (há um espaço marcado para preencher).
